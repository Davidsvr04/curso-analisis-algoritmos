# Curso Análisis de Algoritmos

Repositorio de trabajo para el curso de Análisis de Algoritmos. Aquí se
entregan los cinco informes de laboratorio evaluativos del semestre, junto
con los ejercicios de clase y los benchmarks compartidos de medición de
tiempos.

## Estructura del repositorio

- `laboratorios/`: una carpeta por cada informe de laboratorio evaluativo.
- `ejercicios-clase/`: código de las sesiones prácticas no evaluativas.
- `benchmarks/`: scripts compartidos de medición de tiempos y graficación.
- `README.md`: documentación general del repositorio.
- `.gitignore`: patrones de archivos que no se versionan.

## Uso básico

Para clonar este repositorio y empezar a trabajar:

```bash
git clone <url-del-repositorio>
cd curso-analisis-algoritmos
git status
```
